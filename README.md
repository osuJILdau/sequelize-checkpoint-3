# Контрольная точка №3 — Модели Sequelize

Небольшое консольное приложение про киберспортивные команды и игроков.

## Модели

- **Team** — название и страна команды.
- **Player** — никнейм, роль и `teamId`.
- Связь: одна команда содержит много игроков (**1:N**).

Для связи используются `hasMany` и `belongsTo`.

## Запуск

Нужен Node.js и npm.

```bash
npm install
npm start
```

При запуске программа создаёт SQLite-базу и выводит результаты запросов в терминал. Каждый новый запуск пересоздаёт таблицы с тестовыми данными.

## Что делает программа

1. Показывает всех игроков через `findAll()`.
2. Находит команду по ID через `findByPk()`.
3. Фильтрует команды по стране через `where`.
4. Показывает команды вместе с игроками через `include`.
5. Добавляет нового игрока через `create()`.

В базе создаются **3 команды и 4 игрока** (последний игрок добавляется пятым запросом).

Файл `database.sqlite` создаётся автоматически и не загружается на GitHub.
